プライバシーポリシー

アプリ名: ハマるナビ(Hamaru Navi)
最終更新日: 2026年7月23日

1. 収集する情報について

本アプリ「ハマるナビ」は会員登録・ログインの仕組みを持たず、氏名・メールアドレスなどの個人情報を収集しません。 お気に入り・検索履歴・視聴済みの記録は、すべて利用者の端末内にのみ保存され、外部サーバーへ送信されることはありません。 アプリを削除すると、これらのデータも端末から失われます。

2. TMDB APIの利用について

作品情報・画像の取得のため、The Movie Database (TMDB) が提供するAPIに検索キーワードや作品IDを送信します。氏名・連絡先など個人を特定できる情報を送信することはありません。

This product uses the TMDB API but is not endorsed or certified by TMDB.

3. 広告について

本アプリはGoogle AdMobを利用して広告を配信する場合があります。広告配信にあたり、広告識別子(Advertising ID)などの情報がGoogleおよびその広告パートナーによって取得・利用されることがあります。 詳細はGoogleのプライバシーポリシーをご確認ください。

4. 第三者への情報提供について

本アプリは、上記のTMDB(作品情報取得)およびGoogle AdMob(広告配信、利用時のみ)を除き、取得した情報を第三者へ提供することはありません。
